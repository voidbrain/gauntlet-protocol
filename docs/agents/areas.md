# Area notes

## Protocol

Use strict TypeScript and `unknown` at input boundaries. Reports preserve failed, error and not-run states. Unknown usage never means zero. System fixtures cannot qualify model judgment. A review receipt is an owner attestation, not authenticated identity or production permission.

## Adapters

Only owner-registered fixed commands execute; case packs never carry commands. Supervise complete process groups on supported platforms. External coding runners supply their own security isolation and independent graders. Never describe a subprocess as a sandbox. Consumer implementations and deployment acceptance remain outside this repository.
