# Capability index and evidence reuse

`gauntlet index --packs=examples/smoke-v1.json --out=docs/test-index.md` derives the index from executable cases; `--check` rejects drift. Packs declare a primary `area`, capability tags, layer, regression/holdout split, critical/cost flags and requirements. Missing legacy areas are unclassified, never inferred from names. Namespaced custom areas use `x:project:area`. Empty areas are shown as zero coverage, not proposed or passed tests. Optional `--reports=...` adds measured evidence with original dates and configuration hashes. Never commit a private evidence-backed index without reviewing its contents.

`gauntlet run` automatically checks the per-user private cache at `~/.cache/gauntlet-protocol/evidence`. `--cache-dir=path` selects another private directory for authorized sharing. A complete passing source-stable report can be reused only for the same protocol/grader version, complete case metadata, pack/profile/limits, registry/source fingerprint, observed runtime/model metadata and environment key. The default model environment binds host/hardware, Node and daemon PID/start time. Missing daemon identity disables automatic reuse. System/agent runners require an explicit current `--source-key=<sha256>`; consumers compute it from actual source and adapter inputs.

Default maximum age is seven days, configurable with `--max-age-hours=0..720`. Future-dated, stale, failed, partial, unknown-usage, malformed or mismatched reports never authorize a skip. A changed source/model/runtime/settings/pack causes fresh execution. Preflight reads model metadata; it never generates a response or downloads/starts a model. Registered runners remain trusted code and retain independent source/effect ownership.

Reusing writes an explicitly labelled evidence reference containing the original report/hash/date and `performanceMeasuredNow: false`. It does not create new successful test outcomes, refresh the measurement date, promote a model or grant permissions. `compare`, `qualify` and `readEvidence` accept references without following arbitrary filesystem pointers. Repeated cases do not inflate unique/holdout coverage.

Use `--fresh` for a benchmark, incident reproduction, changed workload or deliberate rerun. Functional evidence reuse is not a new measurement of current latency/memory. Sampler settings are part of the reuse key. Changes outside advertised runtime metadata may not be observable; restart/revoke the evidence or use fresh mode after such changes. A cache is trusted local owner data, not authenticated proof; private ownership/modes and independent review remain necessary. An owner adapter can supply an explicit environment attestation, which is not independent hardware verification.
