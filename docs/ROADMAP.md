# Gauntlet Protocol roadmap

Where the protocol is going next. Each milestone lists its records; steps and estimates live in the records. Planned 2026-11-13 at the owner's request.

| Milestone | Scope | Records | Acceptance |
|---|---|---|---|
| 2 — Broader packs | Structured-output robustness, tool use, bilingual, multi-step agent, refusal, long context | F-012 | Six packs released with regression and holdout splits and grader fixtures |
| 3 — Small hosts | Profiles and environments declare size and memory; misfits refused before a run; small-host presets | F-013 | A model that cannot fit the host is refused at plan time |

Consumers adopt each release in their own backlog: a new or changed case shows as pending in `gauntlet pending` until they run it.
